# Supplier compliance dossier - 2026 Q3

Internal working materials for the Q3 2026 supplier compliance cycle.

- `registers/supplier_register_2026q3.csv` - authoritative supplier register
- `tools/digest_tool.c` - digest utility source
- `BUILD.md` - reproducible build and run instructions

Banding policy (Procurement Standard 4.2):

- risk score >= 700: `escalate`
- 350 <= risk score <= 699: `review`
- risk score < 350: `clear`

The quarterly attestation is published in the release bundle repository; the
shared register in this dossier is not edited in place.
